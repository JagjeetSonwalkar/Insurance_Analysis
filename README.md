# Insurance Analysis Dashboard

## Project Overview

The Insurance Analysis Dashboard is an interactive data analytics project developed using Microsoft Power BI. It focuses on analyzing insurance policy information, customer demographics, premium amounts, coverage amounts, and insurance claims.

The dashboard converts insurance data into meaningful visual insights, allowing users to explore policy performance, compare premium and coverage amounts, understand claim distributions, and monitor claim statuses.

## Dashboard Pages

1. **Dashboard** – Provides an overview of insurance performance through key metrics such as total premium amount, total coverage amount, and total claim amount. It also includes analysis of claim status, gender distribution, policy types, claim amounts by age group, and policy status.
2. **Drill** – Provides detailed insurance and customer information, including customer IDs, policy numbers, claim numbers, age groups, policy dates, policy types, gender, claim status, and claim amounts.
